# Gutenberg Documentation

> **Tài liệu về hệ thống Gutenberg cho Jankx 2.0**

Thư mục này cung cấp hướng dẫn về phát triển block, đăng ký block, hệ thống layout và AJAX trong Gutenberg cho theme Jankx.

## Nội dung chính
- [Blocks](./blocks.md): Danh sách và hướng dẫn sử dụng các block
- [Block Registration](./block-registration.md): Đăng ký block mới
- [Layout System](./layout-system.md): Hệ thống layout cho block
- [AJAX System](./ajax-system.md): Hệ thống AJAX cho block và editor

## Mục tiêu
- Hỗ trợ phát triển block Gutenberg chuyên nghiệp
- Tối ưu hóa trải nghiệm editor và frontend
- Tận dụng tối đa khả năng mở rộng của Gutenberg
