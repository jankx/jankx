# Draft Documentation

## Mục đích

Thư mục `docs/draft/` chứa các tài liệu đã được di chuyển khỏi tài liệu chính vì lý do sau:

- **Outdated Content**: Tài liệu không còn phù hợp với phiên bản hiện tại của framework
- **Under Review**: Tài liệu đang được xem xét và cập nhật
- **Deprecated Features**: Tài liệu về các tính năng đã bị loại bỏ
- **Experimental**: Tài liệu về các tính năng thử nghiệm chưa ổn định

## Nội dung hiện tại

### Gutenberg Blocks (Đã di chuyển)
- `jankx-query-loop-block.md` - Tài liệu về Jankx Query Loop Block
- `jankx-query-loop-classes.md` - Tài liệu về PHP classes cho Query Loop Block

## Quy trình xử lý

### Khi nào di chuyển vào draft?
- Tài liệu chứa thông tin không chính xác hoặc lỗi thời
- Tính năng được mô tả đã bị thay đổi hoặc loại bỏ
- API hoặc syntax đã thay đổi
- Tài liệu cần được viết lại hoàn toàn

### Khi nào khôi phục từ draft?
- Tài liệu đã được cập nhật và kiểm tra
- Tính năng được mô tả đã ổn định
- API đã được finalize
- Nội dung đã được review và approve

### Khi nào xóa hoàn toàn?
- Tính năng đã bị loại bỏ vĩnh viễn
- Tài liệu không còn giá trị tham khảo
- Đã có tài liệu mới thay thế hoàn toàn

## Lưu ý

- Các file trong thư mục draft **KHÔNG** được include trong tài liệu chính
- Các link đến file trong draft sẽ được cập nhật hoặc loại bỏ
- Chỉ developers có quyền truy cập vào thư mục này
- Cần review định kỳ để dọn dẹp các file không còn cần thiết
