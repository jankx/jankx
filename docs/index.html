Modern WordPress Theme Framework

Jankx is a powerful WordPress theme framework built with modern architecture, focusing on performance, maintainability, and developer experience.

Get Started View on GitHub
framework.php 
// Initialize container
$container = Jankx::getInstance();

// Boot kernel by context
$kernelManager = new KernelManager($container);
$kernelManager->boot();

// Automatic context detection
// CLI → Gutenberg AJAX → Cron → REST API → Admin → Frontend

Why Choose Jankx?

High Performance

Deferred service loading, context-aware bootstrapping, and intelligent caching for optimal performance.

Modern Architecture

Layered architecture with dependency injection, service containers, and clean separation of concerns.

Gutenberg Ready

Advanced Gutenberg integration with custom blocks, layout system, and partial hydration.

Developer Friendly

Clean APIs, comprehensive documentation, and modern development tools for better DX.

Secure & Reliable

Built with security best practices, error handling, and graceful degradation.

Community Driven

Open source, actively maintained, and supported by the WordPress community.

Quick Start

1

Install via Composer

composer create-project jankx/jankx my-theme -s dev
2

Activate Theme

Upload the theme to your WordPress installation and activate it from the admin panel.

3

Start Building

Create custom blocks, layouts, and themes using the powerful Jankx framework.

Requirements

  • PHP: >= 7.1
  • WordPress: >= 5.0
