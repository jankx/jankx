Thông tin

CSS này chỉ tập trung vào layout và cấu trúc cơ bản. Màu sắc và style chi tiết sẽ do theme implement.

  • Dropdown: Sử dụng button với class .language-switcher-dropdown và menu .language-switcher-dropdown-menu
  • List: Sử dụng <ul> với class .language-switcher-list
  • Flags: Sử dụng <div> với class .language-switcher-flags
  • Flag: Luôn được hiển thị với class .language-flag
  • Current language: Sử dụng class .current-language
  • Link redirect: Tất cả link đều sử dụng href từ Polylang để redirect
