📝 Usage Examples

Basic Icon Block

<!-- wp:jankx/icon-picker { "iconName": "star", "iconType": "material", "iconStyle": "filled", "iconSize": "24px", "iconColor": "#ffd700" } /-->

Icon with Link

<!-- wp:jankx/icon-picker { "iconName": "heart", "iconType": "material", "iconStyle": "outlined", "iconSize": "32px", "iconColor": "#e74c3c", "linkUrl": "https://example.com", "linkTarget": "_blank" } /-->

Icon with Label

<!-- wp:jankx/icon-picker { "iconName": "phone", "iconType": "material", "iconStyle": "rounded", "showLabel": true, "iconLabel": "Call us", "labelPosition": "after" } /-->

🔧 Technical Details

  • Block Name: jankx/icon-picker
  • Category: widgets
  • Supports: alignment, colors, typography, spacing
  • Icon Types: material, fontawesome, custom
  • Material Styles: filled, outlined, rounded, sharp, two-tone
  • Link Features: URL, target, rel attributes
  • Label Options: 4 positions (before, after, above, below)

📱 Responsive Behavior

Block tự động responsive với các breakpoints:

  • Desktop: Grid layout đầy đủ
  • Tablet: Grid thu nhỏ
  • Mobile: Single column layout

♿ Accessibility Features

  • Screen reader support
  • Keyboard navigation
  • Focus indicators
  • High contrast mode support
  • Reduced motion respect
