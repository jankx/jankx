# Jankx Framework

[![Jankx CI](https://github.com/jankx/jankx/actions/workflows/ci.yml/badge.svg)](https://github.com/jankx/jankx/actions/workflows/ci.yml)

Jankx is a powerful WordPress theme framework. High performance, compatible, easy to use and develop.

## Features

- **Service Provider Pattern**: Modular and extensible architecture.
- **Application Container**: Powerful dependency management.
- **Gutenberg First**: Built from the ground up to support the block editor.
- **Multi-language Support**: Seamless integration with Polylang.
- **High Performance**: Optimized for speed and scalability.

## Installation

```bash
composer install
npm install
npm run build
```

## Development

### Running Tests

```bash
vendor/bin/phpunit
```

### Compiling Assets

```bash
# Development
npm run development

# Production
npm run production
```
